The following is the index and curriculum. The indented outcome of this exam is to demonstrate general working knowledge of the Java Programing Language as defined by Oracle for enterprise environments. 

Each folder corresponds to a concept in Java as well as includes a small project to demonstrate understanding along with a README outlines this as a whole for that corresponding concept.
